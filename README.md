# ShopProject

Учебный проект по дисциплине «Фронтенд и бэкенд разработка».

[Опубликованный сайт](https://zepo4ka.github.io/kr1-html-css-shop/)

## Постановка контрольной работы №1

Тема: «HTML и CSS: разработка многостраничного сайта».

Практические работы последовательно готовят основу сайта интернет-магазина или каталога услуг: семантическую разметку, навигацию, внешний CSS, формы и стили компонентов. Многостраничная структура рассматривается на следующих этапах.

В текущей контрольной реализованы три выбранных пункта:

- №6 — карточки товаров;
- №7 — таблица сравнения характеристик;
- №8 — форма заявки.

## История выполнения

- Практическая работа 1: создан Git-репозиторий, опубликован проект на GitHub Pages.
- Практическая работа 2: создан HTML-каркас стартовой страницы и выполнено базовое CSS-оформление.
- Практическая работа 3: добавлены форма заявки, модальное окно и базовая валидация.
- Практическая работа 4: добавлены CSS-переменные, состояния интерфейса и разделы стилей.
- Контрольная работа: добавлены изображения товаров и таблица сравнения; в итоговой странице сохранены элементы практических работ №2–4.

## Проверка проекта

Откройте `index.html` в браузере. Стили находятся в `css/style.css`, скрипт — в `js/main.js`, изображения — в `images/`.

1. Нажмите «Заказать» на карточке: откроется диалог с названием товара.
2. Проверьте подсказки в полях, обязательные поля, формат e-mail и телефона, согласие на обработку данных.
3. Заполните форму: появится сообщение об успехе, форма сбросится, диалог закроется.
4. Проверьте наведение и видимый фокус при переходе клавишей Tab.

Форма проверяется на стороне браузера. Отправка на backend и сохранение заявок пока не подключены.
