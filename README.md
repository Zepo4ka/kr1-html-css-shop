# ShopProject — учебный каталог товаров

Проект по дисциплине «Фронтенд и бэкенд разработка». Текущая контрольная работа продолжает страницу, созданную в практических занятиях №1–4. Методички №5–7 использованы как справочный материал; отдельные практические работы по ним здесь не выполнялись.

## Контрольная работа: пункты 6, 7 и 8

6. **Карточки товаров:** три карточки с локальными иллюстрациями, названием, описанием, характеристиками, ценой и кнопкой заявки. Карточки размещены в адаптивной CSS-сетке.
7. **Таблица сравнения:** категории, цены, цвета, материалы и назначение товаров сопоставлены в таблице. На узком экране таблицу можно прокрутить горизонтально.
8. **Форма заявки:** открывается из карточки выбранного товара или из отдельного блока страницы. Проверяет обязательные поля, e-mail, длину имени и формат телефона, а также показывает результат проверки.

Форма демонстрационная: данные **не отправляются на сервер и не сохраняются**. Товары и цены также являются учебными примерами.

## Структура проекта

- `index.html` — разделы каталога, таблица сравнения и форма заявки;
- `css/style.css` — внешний CSS-файл с переменными, сеткой и адаптивными стилями;
- `js/main.js` — открытие модального окна, выбор товара и проверка формы;
- `images/` — локальные SVG-иллюстрации трёх товаров;
- `.gitignore` — исключения для Git.

## Как проверить

1. Откройте `index.html` в браузере или перейдите на [GitHub Pages](https://zepo4ka.github.io/kr1-html-css-shop/).
2. Посмотрите три карточки и сравните их с таблицей характеристик.
3. Нажмите «Оставить заявку» в карточке: в форме должно появиться название выбранного товара. Кнопка «Открыть форму заявки» ниже открывает общую форму.
4. Попробуйте проверить пустую форму, затем заполните обязательные поля. Телефон вводится в формате `+7 (900) 000-00-00`.
5. Сузьте окно браузера: карточки перестраиваются, таблица прокручивается внутри своего блока.

## Технологии

HTML, CSS, JavaScript, Git и GitHub Pages. Вёрстка использует семантические элементы, CSS Grid/Flexbox, CSS-переменные и состояния `:hover`/`:focus-visible`.
