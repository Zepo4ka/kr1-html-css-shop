# Учебный frontend-проект

## Описание

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

Тема проекта: многостраничный сайт интернет-магазина или каталога услуг.

## Структура проекта

- `index.html` — главная страница;
- `css/style.css` — файл стилей;
- `js/main.js` — открытие модального окна и обработка формы;
- `images/` — папка для изображений;
- `.gitignore` — список файлов, исключённых из Git;
- `README.md` — описание проекта.

## Используемые технологии

- HTML;

- JavaScript;

## Текущий статус

Создана стартовая страница с кнопками заказа, модальной формой заявки и базовой клиентской валидацией.

## Ссылка на опубликованный проект

GitHub Pages: https://zepo4ka.github.io/kr1-html-css-shop/

## Реализованные элементы интерфейса

- кнопки «Заказать» в карточках трёх товаров;
- модальное окно с формой заявки;
- поля: имя, e-mail, телефон, дата связи, тема, комментарий и согласие;
- проверка обязательных полей, e-mail, минимальной длины имени и формата телефона;
- подсветка ошибочных полей и сообщение «Форма успешно отправлена!».

Форма пока работает только в браузере: заявка не отправляется на сервер и не сохраняется.

Тема контрольной работы №1: «HTML и CSS: разработка многостраничного сайта».

В рамках контрольной работы необходимо разработать многостраничный HTML/CSS-сайт интернет-магазина или каталога услуг.

Проект должен включать:

- главную страницу;
- страницу каталога;
- страницу карточки товара или услуги;
- страницу оформления заявки;
- страницу контактов;

- базовую навигацию;
- оформление основных блоков страницы.
