## Постановка контрольной работы №1

Тема: «HTML и CSS: разработка многостраничного сайта».

Практические работы последовательно готовят основу сайта интернет-магазина или каталога услуг: семантическую разметку, навигацию, внешний CSS, формы и стили компонентов. Многостраничная структура рассматривается на следующих этапах.

В текущей контрольной реализованы три выбранных пункта:

- №6 — карточки товаров;
- №7 — таблица сравнения характеристик;
- №8 — форма заявки.

## История выполнения

- Практическая работа 1: создан Git-репозиторий, опубликован проект на GitHub Pages.
- Практическая работа 2: создан HTML-каркас стартовой страницы и выполнено базовое CSS-оформление.
- Практическая работа 3: добавлены форма заявки, модальное окно и базовая валидация.
- Практическая работа 4: добавлены CSS-переменные, состояния интерфейса и разделы стилей.
- Практическая работа 5: создана отдельная многостраничная версия в `practice-5/`, добавлены единая навигация, якорные ссылки, хлебные крошки и метаданные страниц.
- Практическая работа 6: в отдельной версии `practice-6/` доработаны Flexbox-навигация, Grid-сетка карточек и каталог с боковой областью фильтров.
- Контрольная работа: добавлены изображения товаров и таблица сравнения; в итоговой странице сохранены элементы практических работ №2–4.

## Проверка проекта

Откройте `index.html` в браузере. Стили находятся в `css/style.css`, скрипт — в `js/main.js`, изображения — в `images/`.

1. Нажмите «Заказать» на карточке: откроется диалог с названием товара.
2. Проверьте подсказки в полях, обязательные поля, формат e-mail и телефона, согласие на обработку данных.
3. Заполните форму: появится сообщение об успехе, форма сбросится, диалог закроется.
4. Проверьте наведение и видимый фокус при переходе клавишей Tab.

Форма проверяется на стороне браузера. Отправка на backend и сохранение заявок пока не подключены.

1. Откройте `practice-5/index.html` и перейдите в каталог и контакты через общее меню.
2. С каждой страницы проверьте ссылки «Преимущества», «Популярные товары» и «Обратная связь» — они ведут на разделы главной страницы этой версии.

## Практическая работа №6

Версия для шестой работы находится в `practice-6/` и продолжает пятую работу. Сайты контрольной и пятой работы сохранены без изменений.

### Структура шестой работы

- `practice-6/index.html` — главная страница с сеткой популярных товаров;
- `practice-6/catalog.html` — каталог с фильтрами слева и товарами справа;
- `practice-6/contacts.html` — контактная информация;
- `practice-6/css/style.css` — общие стили с Flexbox и CSS Grid;
- `practice-6/js/main.js` — сохранённая форма заявки на главной странице;
- `images/` — общие изображения товаров.

### Использование Flexbox и Grid

- `.site-nav__list` — Flexbox: `justify-content`, `align-items`, `gap` и перенос пунктов меню;
- `.product-card` — Flexbox в столбец, кнопка внизу через `margin-top: auto`;
- `.products-grid` — CSS Grid с тремя равными колонками;
- `.catalog-layout` — CSS Grid с колонками `260px` и `1fr`, именованными областями `filters` и `products`;
- `.catalog-filters` и `.catalog-products` — размещение через `grid-area`;
- `.filters-form` — CSS Grid для промежутков между группами полей.

### Проверка шестой работы

1. Откройте `practice-6/index.html`: проверьте меню, сетку карточек и форму заявки.
2. Перейдите в каталог: фильтры находятся слева, сетка товаров — справа.
3. Проверьте checkbox категорий, числовые поля цены и кнопку «Применить».
4. Проверьте переходы между страницами, якоря и хлебные крошки.
5. В DevTools выберите меню, сетку карточек и макет каталога; проверьте `display`, `gap`, `grid-template-columns`, `grid-template-areas` и `grid-area`.

Форма фильтров добавлена для изучения HTML-разметки и CSS-раскладки. При отправке параметры попадают в URL, но JavaScript-фильтрация товаров не реализована и в практической №6 не требуется.
