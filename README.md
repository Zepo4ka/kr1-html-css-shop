# Контрольная работа

В проекте реализованы три пункта задания:

- №6 — карточки товаров;
- №7 — таблица сравнения характеристик;
- №8 — форма заявки с полями «Имя», «Email» и «Сообщение».

Откройте `index.html` в браузере. Стили находятся в `css/style.css`, скрипт формы — в `js/main.js`, изображения товаров — в `images/`.

Форма проверяет поля в браузере. Серверная отправка не подключена.
