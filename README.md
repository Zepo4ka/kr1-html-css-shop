# ShopProject

Учебный проект по дисциплине «Фронтенд и бэкенд разработка».

[Опубликованный сайт](https://zepo4ka.github.io/kr1-html-css-shop/)

[Практическая работа №5](https://zepo4ka.github.io/kr1-html-css-shop/practice-5/)

## Постановка контрольной работы №1

Тема: «HTML и CSS: разработка многостраничного сайта».

Практические работы последовательно готовят основу сайта интернет-магазина или каталога услуг: семантическую разметку, навигацию, внешний CSS, формы и стили компонентов. Многостраничная структура рассматривается на следующих этапах.

В текущей контрольной реализованы три выбранных пункта:

- №6 — карточки товаров;
- №7 — таблица сравнения характеристик;
- №8 — форма заявки.

## История выполнения

- Практическая работа 1: создан Git-репозиторий, опубликован проект на GitHub Pages.
- Практическая работа 2: создан HTML-каркас стартовой страницы и выполнено базовое CSS-оформление.
- Практическая работа 3: добавлены форма заявки, модальное окно и базовая валидация.
- Практическая работа 4: добавлены CSS-переменные, состояния интерфейса и разделы стилей.
- Практическая работа 5: создана отдельная многостраничная версия в `practice-5/`, добавлены единая навигация, якорные ссылки, хлебные крошки и метаданные страниц.
- Контрольная работа: добавлены изображения товаров и таблица сравнения; в итоговой странице сохранены элементы практических работ №2–4.

## Проверка проекта

Откройте `index.html` в браузере. Стили находятся в `css/style.css`, скрипт — в `js/main.js`, изображения — в `images/`.

1. Нажмите «Заказать» на карточке: откроется диалог с названием товара.
2. Проверьте подсказки в полях, обязательные поля, формат e-mail и телефона, согласие на обработку данных.
3. Заполните форму: появится сообщение об успехе, форма сбросится, диалог закроется.
4. Проверьте наведение и видимый фокус при переходе клавишей Tab.

Форма проверяется на стороне браузера. Отправка на backend и сохранение заявок пока не подключены.

## Практическая работа №5

Версия для пятой работы находится в папке `practice-5/`. Главная страница контрольной работы в корне репозитория сохранена без изменений.

### Структура проекта

- `index.html`, `css/style.css`, `js/main.js` — текущий сайт контрольной работы;
- `practice-5/index.html` — главная страница пятой работы;
- `practice-5/catalog.html` — каталог товаров;
- `practice-5/contacts.html` — контактная информация;
- `practice-5/css/style.css` — общие стили трёх страниц;
- `practice-5/js/main.js` — форма заявки на главной странице;
- `images/` — общие изображения товаров;
- `README.md` — описание проекта;
- `.gitignore` — файлы, исключённые из Git.

### Проверка пятой работы

1. Откройте `practice-5/index.html` и перейдите в каталог и контакты через общее меню.
2. С каждой страницы проверьте ссылки «Преимущества», «Популярные товары» и «Обратная связь» — они ведут на разделы главной страницы этой версии.
3. На внутренних страницах проверьте хлебные крошки: «Главная» — ссылка, текущая страница — текст.
4. В исходном коде проверьте уникальные `title` и `meta description`, один `main` и общий CSS.
5. Нажмите «Заказать» на главной и проверьте сохранённую форму, обязательные поля и checkbox.

Контактные данные в пятой работе — примеры из методички. Серверная отправка формы не подключена.
