# Практическая работа №8 — итог КР №1

Тема: «HTML и CSS: разработка многостраничного сайта».

ShopProject — учебный интернет-магазин с каталогом, подробными характеристиками товаров и формой заявки. Эта версия продолжает №7 и находится отдельно в `practice-8/`. Корневая контрольная и практические №5–7 не изменены.

[Файлы версии №8](https://github.com/Zepo4ka/kr1-html-css-shop/tree/main/practice-8)

## Структура

- `index.html` — главная: первый экран, преимущества, популярные товары, сравнение и модальное окно;
- `catalog.html` — каталог с категориями и статическими фильтрами;
- `product.html` — изображения, описания и таблицы характеристик трёх товаров; каждый товар доступен по своему якорю;
- `order.html` — самостоятельная страница заявки;
- `contacts.html` — контактная информация и ссылка на заявку;
- `css/style.css` — общий внешний CSS;
- `js/main.js` — диалог, базовая проверка формы и выбор товара из ссылки;
- `../images/` — изображения товаров;
- `README.md` — описание итоговой версии;
- `../.gitignore` — исключения общего Git-репозитория.

## Технологии и обязательные элементы

HTML5, CSS3, минимальный JavaScript, Git, GitHub и GitHub Pages. CSS-фреймворки не используются.

- Семантические `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`.
- Единое меню, хлебные крошки и якорные ссылки; уникальные title и meta description.
- Карточки товаров, Grid-каталог с боковой областью, Flexbox-меню и внутренняя структура карточек.
- Таблицы с caption, thead, tbody, th и td.
- Именованные БЭМ-блоки, элементы и модификаторы; CSS-переменные, hover, focus-visible и disabled.
- Форма с именем, e-mail, телефоном, датой связи, темой, комментарием и обязательным согласием; на странице заявки также есть выбор товара.
- Модальное окно dialog сохранено на главной.
- Карточка использует `position: relative`, бейдж — `absolute`, боковой фильтр — `sticky`, кнопка «Наверх» — `fixed` с `z-index`.

## Сценарий заявки

Из каталога ссылка «Подробнее» ведёт к соответствующему товару на `product.html#urban`, `#city` или `#wave`. Кнопка заявки ведёт на `order.html?product=...`, где товар и тема «Заказ товара» выбираются автоматически.

На главной «Заказать» открывает диалог с названием выбранного товара. Пустые и неверно заполненные обязательные поля отмечаются при проверке. После успешной проверки показывается сообщение, форма сбрасывается, диалог закрывается.

Формы работают только в браузере: отправка на сервер и хранение заявок не подключены. Фильтры каталога — статическая HTML-разметка, а не JavaScript-фильтрация. Контактные данные учебные.

## Как открыть и проверить

Откройте опубликованный сайт или файл `index.html` этой папки. Для локального просмотра всего репозитория можно запустить из его корня:

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

Затем откройте `http://127.0.0.1:8765/practice-8/`.

1. Проверьте все пять страниц, меню, якоря и хлебные крошки.
2. В каталоге проверьте сетку, фильтры, checkbox категорий и поля цены с min=0.
3. Откройте «Подробнее» для каждого товара, проверьте изображения, цены и таблицы.
4. Перейдите к заявке из карточки: должен быть выбран соответствующий товар.
5. Проверьте пустую форму, неверный e-mail/телефон, обязательное согласие, успешную проверку и сброс.
6. На главной проверьте диалог и кнопку закрытия.
7. Клавишей Tab проверьте видимый фокус. В DevTools посмотрите Flex/Grid, grid-area, БЭМ-классы и позиционирование.
8. Проверьте, что корневой сайт и `practice-6/` доступны по прежним адресам.

## Доработки проекта

Вместо безымянных карточек используются три товара с изображениями и характеристиками. Переходы связывают каталог, описание конкретного товара и заранее заполненную заявку. Для навигации добавлены активный пункт меню, хлебные крошки и «Наверх». Сохранены подписи полей, подсказки, видимый фокус и доступные сообщения проверки.
